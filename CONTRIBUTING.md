# Como contribuir

1. Abra uma Issue descrevendo problema, objetivo e critérios de aceite.
2. Crie uma branch: `git switch -c feat/nome-da-mudanca`.
3. Altere apenas os arquivos relacionados à tarefa e confira os links.
4. Use commits descritivos, por exemplo `feat: adiciona filtro de projetos`.
5. Envie a branch e abra um Pull Request para `main`.
6. Descreva a alteração e como foi validada; revise o diff antes do merge.

Em trabalho individual, faça autorrevisão. Não declare revisão por pares sem participação efetiva de outra pessoa. Não envie senhas, tokens ou dados pessoais de terceiros.
