# Study Hub TI

## Sobre o Projeto

O **Study Hub TI** é um repositório criado com o objetivo de organizar e documentar minha trajetória acadêmica e profissional na área de Tecnologia da Informação.

Este espaço será utilizado ao longo da minha formação para reunir disciplinas, atividades acadêmicas, anotações, resumos, projetos e certificados.

Além de facilitar a organização dos estudos, o Study Hub também funcionará como um registro da minha evolução acadêmica e como base para a construção do meu portfólio profissional.

O principal objetivo deste repositório é criar uma estrutura organizada para acompanhar minha trajetória durante o curso.

- Organizar atividades e entregas acadêmicas;

## Organização das Pastas


### 01_Apresentacao_e_Perfil

Diretório destinado às informações relacionadas à minha apresentação acadêmica e profissional.



### 02_Disciplinas_Atuais

Diretório responsável por organizar os conteúdos das disciplinas cursadas atualmente.

Cada disciplina poderá possuir sua própria estrutura de pastas para atividades, entregas, anotações e materiais de estudo.



### Bootcamp I

Diretório referente à disciplina Bootcamp I.

Sua organização é dividida em:
Atividades_e_Entregas: atividades e trabalhos desenvolvidos durante a disciplina;
Anotacoes_e_Resumos: anotações, resumos e materiais utilizados durante os estudos.



### 03_Projetos_e_Certificados

Diretório destinado ao armazenamento dos projetos desenvolvidos durante minha formação e dos certificados obtidos em cursos, eventos e atividades complementares.



## Evolução do Study Hub

Este repositório será atualizado continuamente durante minha trajetória acadêmica.

À medida que novas disciplinas, projetos e experiências forem desenvolvidos, novas pastas e conteúdos serão adicionados mantendo o padrão de organização estabelecido inicialmente.

Dessa forma, o Study Hub poderá representar de maneira organizada a evolução dos meus conhecimentos e habilidades ao longo da graduação.




## Etapa Intermediária - Bootcamp I

A etapa intermediária dá continuidade à organização definida na entrega inicial. O objetivo é ampliar o Study Hub TI com uma página de portfólio, projetos documentados e boas práticas de versionamento.

### Materiais preparados para inclusão

- **Portfólio Web:** página em HTML e CSS para apresentar o perfil acadêmico e os projetos, preparada para GitHub Pages.
- **Ciclo de Estudos:** projeto pessoal em HTML, CSS e JavaScript para organizar sessões de estudo, calcular a carga horária semanal e exportar os dados em JSON.
- **Documentação:** READMEs dos projetos, guia de publicação, orientações de colaboração e roteiro de apresentação.

### Ampliação planejada da estrutura

As pastas da entrega inicial serão preservadas. Os novos arquivos estão organizados no pacote da etapa intermediária da seguinte forma:

```text
02_Disciplinas_Atuais/Bootcamp_I/Atividades_e_Entregas/Etapa_Intermediaria/
03_Projetos_e_Certificados/Projetos_Academicos/Portfolio_Web/
03_Projetos_e_Certificados/Projetos_Pessoais/Ciclo_de_Estudos/
04_Documentacao/
docs/index.html
docs/ciclo/index.html
```

### Versionamento

O fluxo previsto utiliza branches por alteração, commits descritivos e Pull Requests para a branch `main`. A primeira versão funcional do portfólio será identificada por uma tag, seguida de alterações registradas no histórico para demonstrar a evolução do projeto.

### Publicação e compartilhamento

A página será publicada pelo GitHub Pages a partir da pasta `docs` da branch `main`. Após confirmar a publicação, o endereço será incluído neste README e no perfil do LinkedIn. A apresentação em vídeo demonstrará a estrutura do repositório, os projetos e o histórico de alterações.

**Situação desta etapa:** materiais preparados; inclusão dos arquivos, registro das versões, publicação, integração com LinkedIn e vídeo pendentes de conclusão.
