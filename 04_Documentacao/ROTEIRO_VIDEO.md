# Roteiro de apresentação - aproximadamente 5 minutos

Use como apoio e fale com suas palavras. Abra as páginas e o GitHub antes de gravar. Apresente publicações apenas depois de realizá-las.

## 0:00 a 0:40 - Apresentação
“Olá, sou Luís Flávio Góis da Silva, estudante de Análise e Desenvolvimento de Sistemas no CEUB. Vou apresentar a etapa intermediária do Study Hub TI, desenvolvido em Bootcamp I. O objetivo é organizar minha trajetória acadêmica e transformar o repositório em um portfólio profissional. Tenho interesse em cibersegurança, desenvolvimento de software e cloud computing.”

## 0:40 a 1:30 - Continuidade e estrutura
Mostre o README raiz e abra as pastas. Explique: “A etapa inicial organizou o perfil, as disciplinas e as entregas. Preservei essa estrutura e acrescentei projetos acadêmicos, projetos pessoais e documentação. Os arquivos do site ficam em docs, para publicação com GitHub Pages. Cada projeto possui um README com objetivo, tecnologias, execução e limitações.” Abra a entrega inicial e a intermediária para mostrar a continuidade.

## 1:30 a 2:25 - Portfólio
Abra o endereço publicado. Navegue pelo perfil, pelos projetos e pela trajetória. Mostre a adaptação à tela menor. Explique: “A página utiliza HTML e CSS, sem instalação ou backend. Ela apresenta meu perfil e oferece acesso ao código e aos trabalhos. A publicação usa a pasta docs da branch main. Os materiais da etapa inicial também são acessados pela área de trajetória.” Mostre esses materiais quando estiverem vinculados.

## 2:25 a 3:20 - Projeto pessoal
Abra Ciclo de Estudos. Adicione Banco de Dados, segunda-feira, 50 minutos; adicione Java, terça-feira, 40 minutos. Mostre o total de 1h30. Recarregue a página, remova uma sessão e exporte o JSON. Explique que JavaScript manipula a lista, valida os campos e utiliza localStorage. O armazenamento é local, sem sincronização entre dispositivos.

## 3:20 a 4:15 - Git e colaboração
Abra commits, tag v1.0.0 e os PRs reais. Mostre a primeira versão e a alteração posterior. Explique o fluxo: branch, implementação, commit, push, revisão e merge. Destaque a diferença entre Git local, GitHub como hospedagem e GitHub Pages como publicação da página. Explique que os commits permitem rastrear mudanças e que, nesta entrega individual, houve autorrevisão.

## 4:15 a 5:00 - Integração e conclusão
Mostre o projeto no seu LinkedIn e os links no PDF final. Diga: “A integração facilita compartilhar o portfólio em contextos acadêmicos e profissionais. A etapa intermediária acrescentou uma página navegável, um projeto funcional e documentação do processo. Como próximos passos, pretendo incluir outros projetos e ampliar os registros de estudo. Obrigado.”

Faça uma gravação de ensaio. Ajuste o ritmo e use o tempo das demonstrações para chegar próximo de cinco minutos, sem ler comandos ou informações pessoais na tela.
