# Portfólio Web - Study Hub TI

## Problema e objetivo
O repositório organiza os estudos, mas precisa de uma apresentação visual acessível. O portfólio reúne perfil, trajetória, projetos e links para a documentação.

## Tecnologias e arquivos
HTML5 e CSS3, sem dependências. Código em `docs/index.html` na raiz do repositório.

## Execução
Abra `docs/index.html`. Para publicar, utilize GitHub Pages com `main` e `/docs`.

## Funcionalidades
Navegação por seções, apresentação acadêmica, acesso ao GitHub, projeto pessoal e layout responsivo.

## Validação
Conferir navegação, links, leitura em celular e acesso público após implantação.

## Limitações
O portfólio não possui backend. Vídeo, slides e documentos anteriores devem ser vinculados quando seus endereços reais estiverem disponíveis.
