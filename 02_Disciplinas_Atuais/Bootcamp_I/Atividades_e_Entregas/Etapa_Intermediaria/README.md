# Entrega intermediária - Bootcamp I

## Continuidade
A etapa inicial definiu identidade, disciplinas e diretórios do Study Hub TI. Esta etapa acrescenta uma interface web, um projeto pessoal, documentação de publicação e um processo de versionamento.

## Materiais
- Portfólio: `docs/index.html`, na raiz do repositório.
- Planejador: `docs/ciclo/index.html`.
- Documentação: `04_Documentacao/`.
- Relatório editável: `04_Documentacao/RELATORIO_ENTREGA.md`.
- Roteiro de 5 minutos: `04_Documentacao/ROTEIRO_VIDEO.md`.

## Aceite
1. Portfólio e planejador abrem e funcionam.
2. Alterações estão registradas em commits e tag.
3. GitHub Pages está acessível sem autenticação.
4. Link está incluído no LinkedIn.
5. Vídeo está publicado e acessível.
6. PDF final inclui os links reais e as evidências.

A existência dos arquivos locais não comprova os itens de publicação. Conferir o guia antes de enviar.
